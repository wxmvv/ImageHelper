# ImageHelper 隐私政策

[English](PRIVACY.md) · **简体中文** · [返回 README](../README_CN.md)

生效日期为 2026 年 11 月 18 日。本政策适用于 ImageHelper 的 Chrome 和 Safari 扩展。

ImageHelper 在你的设备上处理提取结果。扩展没有账户系统、开发者运营的后端、广告或使用分析功能。项目不会出售扩展用户数据。

## 网站访问与图片提取

在浏览器允许访问的网站上，ImageHelper 可读取页面标题、页面及框架地址，以及页面内容和样式中的图片引用。为了发现较早加载或动态出现的图片，扩展可观察资源加载记录，并从支持的 `fetch` 和 `XMLHttpRequest` 响应中查找图片地址。打开结果页之前，扩展可能已在当前网页内暂存候选地址。这些信息用于展示来源页面和图片结果，包括可获取的尺寸、文件大小和替代文本。

使用多地址提取时，扩展在后台标签页打开你提交的网址，在本地合并结果，并关闭它为此次提取打开的标签页。

## 网络请求与数据共享

打开你提交的页面、显示网站图标、加载缩略图和预览、比较相似图片或下载文件时，ImageHelper 会向相应网站或图片所在服务器发起请求。接收方可能收到请求地址和 IP 地址等常规请求信息。在请求和浏览器设置允许时，浏览器可能发送 Cookie 或来源页面信息（Referer）。

ImageHelper 在本地生成 ZIP 并通过浏览器保存下载。选择复制操作时，扩展会将图片链接写入剪贴板。提取结果和设置不会发送给开发者。

## 本地存储与控制

设置和已保存的筛选条件存放在浏览器本地。提取会话可能包含页面和图片地址，优先保存在浏览器会话存储中，也可能在会话存储不可用时存入扩展本地存储，以便在后台进程重启等中断后恢复结果。关闭或离开来源标签页时，扩展会尝试清除对应的会话快照。

你可在扩展选项中控制是否将 CSS 扫描、网络资源和页面请求钩子发现的图片纳入结果。要调整网站访问权限或停用 ImageHelper，请使用浏览器的扩展管理功能。使用浏览器提供的数据清理或卸载功能可移除扩展数据。已下载的文件可单独删除。

## Chrome 网上应用店的数据使用限制

ImageHelper 通过 Chrome API 获取的信息按 [Chrome 网上应用店用户数据政策](https://developer.chrome.com/docs/webstore/program-policies/limited-use)的有限使用要求处理，用于提供图片提取、预览、筛选和下载功能。

## 联系与变更

隐私问题可通过 [GitHub Issues](https://github.com/wxmvv/ImageHelper/issues) 反馈。Issue 是公开的，请不要附上私有链接、登录凭据或个人信息。政策变更将在本页公布，并更新生效日期。
