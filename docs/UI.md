# ImageHelper — 界面规范 (UI)

界面保持紧凑，突出主要操作。
所有页面共用 `ui/styles/tokens.css` 与 `base.css`。


- 空状态：图标 + 「未发现图片」+ 说明（尝试自动滚动）+ `重新扫描` 按钮。
- 筛选为空：显示「当前筛选无结果」+ `重置筛选`。
- 网格使用 `IntersectionObserver` 懒加载缩略图，`rootMargin: 600px`，并发 8。
- 卡片 `content-visibility: auto` 保证长列表流畅。

## 大图预览

全屏遮罩 `rgba(0,0,0,.92)`：图片居中 `object-fit: contain`，滚轮以指针为中心缩放（0.1×–8×），
拖动平移，`←/→` 切换，底部浮条显示序号/尺寸/体积/URL 与 `下载`、`复制`、`新标签` 按钮。

## Popup 380×220

品牌行（16px 图标 + ImageHelper）→ 主按钮「提取本页图片」(accent，整行) →
次级列表：多地址提取 / 选项 / 快捷键说明（Alt+Shift+Y）。底部一行灰字：当前页域名。

可在外观设置中开启透明弹窗背景，默认关闭。透明模式使用高对比文字及半透明的悬停和键帽底色。

## 选项页

左侧竖排导航（嗅探 / 尺寸 / 下载 / 外观 / 快捷键 / 关于），右侧表单卡片。控件：开关、数字输入、
select、文本框、命名模板预览（实时显示示例文件名）。保存即生效（`input` 防抖 400ms）。

快捷键卡片支持录入「提取本页图片」的组合键并自动保存，可清除。网页输入框与可编辑区域中不触发；
默认显示 `Alt+Shift+Y`，清除后保持为空并停用提取快捷键；重置设置可恢复默认值。
侧边栏选中项仅用背景填色表示，不显示左侧竖线。

## 多地址提取

顶部说明 + textarea（每行一条 URL）+ `开始提取`；下方进度列表（每条：URL / 状态 / 图片数）；
完成后 `下载全部 (ZIP)` + `复制全部链接`。

## 组件与类名

`ih-button`（`--primary` `--ghost` `--icon` `--danger`）、`ih-chip`（`--on`）、`ih-input`、
`ih-select`、`ih-switch`、`ih-field`、`ih-card`、`ih-badge`、`ih-toolbar`、`ih-empty`。
不使用内联样式表达视觉；动态值（宽度/位置）可内联。
